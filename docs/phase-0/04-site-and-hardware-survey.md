# Site, network & hardware survey

A half-day site walk with the engineering head and whoever manages IT.

## 1. Site map
- [ ] Drone photo of the whole property (top-down, high resolution) for tracing the 3D model accurately
- [ ] Confirm every building's use, floors and room numbers against the Phase 1 model
- [ ] Mark entrances, parking, staff entrance, service roads, assembly points
- [ ] Mark CCTV camera positions

## 2. Network
- [ ] Internet lines: providers, speeds, where they enter
- [ ] Current Wi-Fi access points and dead spots (walk with a phone running a speed test): every building, lawns, grounds, pool, kitchen, stores, staff quarters
- [ ] Server / IT room: space, power, UPS, cooling for the edge box
- [ ] Wired network points available at front desk, restaurant cashier, kitchen stations, bar, stores

## 3. Hardware already on site
- [ ] PCs and printers at front desk, restaurant, bar, kitchen, stores, accounts (model and age)
- [ ] Thermal printers (model, USB or network)
- [ ] Card machines and UPI QR standees
- [ ] Door lock encoder (brand, model, software version)
- [ ] Biometric devices
- [ ] CCTV recorder (brand, model, remote access available?)

## 4. Indoor positioning plan
- [ ] List of rooms and zones where staff location matters (each Park Wing floor, kitchen, stores, halls, laundry)
- [ ] Beacon positions per zone (target: one per floor per wing, one per major room)
- [ ] QR checkpoint positions for patrols and public-area cleaning

## 5. Output
- Hardware purchase list with quantities and budget
- Wi-Fi upgrade plan (outdoor mesh for lawns and grounds)
- Updated 3D site file for Phase 2
